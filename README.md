# Brainwasher Pro

A clean window for the Goblin Brainwashing Device's talent specs, for World of
Warcraft 1.12.1. Requires ClassicAPI.

- Talk to the device and Brainwasher Pro replaces its menu: one row per talent slot.
- Click a spec's icon to activate it; buying a slot or resetting talents asks first.
- The spec you are in now is marked **Active**, so you never swap to it by accident.
  Two specs with the same talent split are told apart by their talents once
  you have saved or activated them here.
- **Save** stores your current talents in that slot and says which spec it replaces.
- Each slot shows its talent split; hover a row for the full names.
- **Edit** names the spec and picks its icon, from spell and item icons.
- With [ActionBarProfiles](https://github.com/Fostercare5988/ActionBarProfiles)
  installed, Edit can also link an action bar profile. It loads once the new
  talents are in place (after combat, if you are fighting). A profile you have
  since deleted shows as "Bars: missing".
- **Show original** brings back the device's own menu.

## Install

Download `BrainwasherPro.zip` from the [latest release](https://github.com/Fostercare5988/BrainwasherPro/releases/latest) and extract it into
`Interface/AddOns`.
